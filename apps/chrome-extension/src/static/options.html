Docs Compare 站点配置

每一项是一对「原站 ↔ 你的汉化镜像」。保存后立即生效,无需重新加载扩展。

字段说明

{
  "id":                  "唯一 id,如 react"
  "origin":              "原站,如 https://react.dev"
  "mirror":              "汉化站,如 https://you.github.io/react-zh(可含仓库路径)"
  "originPrefix":        "可选:原站还需剥离的前缀,如 /docs"
  "mirrorPrefix":        "可选:汉化站还需剥离的前缀"
  "originStripHtmlExt":  "可选:true 表示该侧 URL 带 .html 而对侧是干净路径"
  "anchorMapUrl":        "可选:锚点表地址。绝对 URL(如镜像站 /anchor-map.json),或扩展内打包路径(如 anchor-maps/orca.json,由 scripts/gen-anchor-map.mjs 同步生成)。默认 mirror/anchor-map.json"
  "css": { "origin": "专注模式注入原站的 CSS", "mirror": "注入汉化站的 CSS" }
}

anchor-map.json 格式

构建汉化站时生成,放在镜像根目录(或用 anchorMapUrl 指定)。路径用归一化形式(不带 .html、不带尾斜杠):

{
  "/learn/hooks": { "安装-react": "installing-react", "使用钩子": "using-hooks" }
}

内层方向:键 = 汉化站锚点,值 = 原站锚点,均不含 #。查不到的锚点会原样透传。
